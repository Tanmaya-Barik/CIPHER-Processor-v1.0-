CIPHER Processor [v1.0]

A web-based, cyber-themed encryption terminal that utilizes a monoalphabetic substitution cipher to securely encrypt and decrypt messages.

Built with a lightweight Python/Flask backend and an immersive, animated front-end interface, this tool is designed for speed, responsiveness, and a high-tech aesthetic.

✨ Features

Cryptographic Engine: Accurately encrypts and decrypts text using a custom 26-character unique substitution key.

Cybernetic UI: Features an immersive, deep-space blue design with an animated glowing circuit background.

Asynchronous Processing: Uses JavaScript fetch API to communicate with the Python server without reloading the page.

Fully Responsive: Fluidly adapts to desktop monitors, tablets, and mobile devices.

Production Ready: Configured with gunicorn for seamless deployment to modern web hosting platforms.

🛠️ Tech Stack

Frontend: HTML5, CSS3 (Custom Animations), Vanilla JavaScript

Backend: Python 3, Flask

Deployment: Gunicorn


📖 How to Use

Enter your secret message (Plaintext) or encrypted message (Ciphertext) into the Input Data console.

Provide a Functional Key. This must be exactly 26 unique alphabetical characters (e.g., QWERTYUIOPASDFGHJKLZXCVBNM).

Click Encrypt [E] or Decrypt [D].

Retrieve your processed data from the Output Console.

System initialization complete. Standing by.
